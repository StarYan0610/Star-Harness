# skeleton-first

## 适用场景

适用于从 0 到 1 搭建项目，或为已有项目增加一个较完整的新模块。

## 拆分规则

1. 第一批任务必须先建立项目骨架、配置、目录结构和最小运行闭环。
2. 骨架任务最多实现 3 个以内对外接口或命令。
3. 后续任务按功能一、功能二、功能三拆分。
4. 每个任务都必须包含验收标准。
5. 每个任务都必须说明预计修改范围。
6. 默认最多 6 个任务，硬上限 8 个任务。

## 输出格式

每个任务输出：

- title
- description
- scope
- acceptance_criteria
- verification_commands
